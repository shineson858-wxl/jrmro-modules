## 二、业务背景与目标

### 2.1 背景
MRO 工业品采购具有**大额、批量、价格面议**的特点，传统电商的固定价+即时下单无法满足；采购方需要询价、比价、报价确认后再成交。

### 2.2 产品目标
1. 提供完整的 MRO 商品展示、搜索、多语言浏览体验。
2. 打通「购物车 → 询价 → 报价 → 订单 → 签章」的单据闭环。
3. 支持越南本地化：越南盾、越南语、越南行政区划地址、越南税率/汇率。
4. 提供高效的商品维护：电子表格批量导入 + 后台增强管理。

### 2.3 成功标准（初始）
- 客户可在前台完成浏览、询价、购物车生成报价、下单。
- 后台可在一个「单据中心」统一管理询价/报价/订单。
- 报价单支持调价、税率/汇率调整、多语种文档、导出与邮件。
- 商品可通过 CSV/XLSX 批量导入并配图。

## 五、功能需求

### F1 前台浏览
- 首页：头图、新品上架、热门分类、商品网格（带图 + VND 价）。
- 分类：横楣 13 顶级大类 + 图标 + 抽屉菜单 + 条件筛选 + 排序。
- 详情：多图、规格、价格（按汇率换算 VND）、库存、加入购物车/购买/询价。
- 搜索：关键词检索（多语言）。

### F2 多语言（4 种）
- 简体中文（默认）/ 繁体中文 / 越南语 / 英文。
- 范围：界面文案、分类、属性选项、商品名、站点品牌、报价单文档。
- 切换：右上角选择器 + URL `?locale=xx`。

### F3 购物车与下单
- 购物车：增删改数量、合计（VND）、生成报价单入口。
- 结账：收货地址（**越南行政区划**三级联动）、配送方式、支付方式（COD / Vietcombank 转账）。
- 订单：确认、状态、发票、邮件通知。

### F4 询价（RFQ）
- 入口：商品详情页「我要询价」。
- 表单：姓名/邮箱/数量/电话/公司/留言（游客亦可）。
- 数据：写 `mro_rfqs`，状态 `pending → quoted → accepted → closed`。
- 通知：新询价通知管理员；后台报价后邮件通知客户。

### F5 购物车生成报价单
- 入口：登录客户购物车页「生成 MRO 标准报价单」。
- 行为：读取购物车全部商品 → 生成草稿报价单（默认税率/汇率）→ 后台可调价/改税/汇率。
- 报价单号 `Q<id>`，多语种标准文档，可导出 Excel/PDF、邮件发客户、打印。

### F6 单据中心（统一交易入口）
- 顶级菜单「单据中心」，**20 个子菜单**：报价单 / 快速报价 / 询价单 / 订单 / 配送自提 / 协议价 / 到货通知 / 对账报表 / 客户360 / 业务员业绩 / 经营看板 / 销售分析 / 合同模板 / 商品资料/替代 / 公司成员 / 进价/毛利 / 库存预警 / 周期采购 / 补货计划单 / 上架审核。
- 概览：三类单据状态卡片 + 最近单据 + 快捷入口 + 流转说明。

### F7 订单与签章
- 报价 confirmed 后生成订单。
- 订单状态：`pending_sign → signed → completed / cancelled`。
- 签章：卖方 + 客户**记录式签章**（`mro_signatures`：签署方/时间/内容哈希），哈希锁定防篡改；篡改实时校验告警。
- 审计：关键操作写 `mro_audit_logs`（操作人/IP/变更前后值）。

### F8 商品导入与后台管理
- 电子表格导入：CSV/XLSX，含下拉选项、校验、`images` 列支持本地文件与 URL。
- 批量操作：改价/库存/移分类/复制（含图可选）。
- 行内快速编辑、图片库（集中管理/批量删）、批量传图（ZIP/多文件按 SKU）。
- 定时自动导入（默认每日 08:00，可配置）+ 导入历史可视化。
- 手动维护商品（精简 4 语言表单）。

### F9 货币 / 税 / 汇率
- 货币：VND（基准）/ CNY / USD。
- 商品按 CNY 基准价存储，前台按汇率换算 VND。
- 税率默认 10%、汇率默认 3500（后台报价单可全局配置 + 单笔覆盖）。

### F10 通知
- 邮件：注册、订单、发票、询价提交、报价通知（含 PDF 附件）。

### F11 运营看板与分析（Phase 3 · L1/L2）
- 经营看板：今日/本月已收款成交（CNY+单数）、待处理询价/报价/订单、客户欠款、Top 商品（按销量）、Top 客户、缺货商品数、近 30 天成交趋势（Chart.js）。
- 销售分析：客户销售汇总、商品 ABC 分析（累计占比 70/90 分 A/B/C）、CSV 导出（带 BOM）。

### F12 企业客户与价格（Phase 3 · H3/H4/H2）
- 公司多采购员账号 + 角色（Owner/Buyer/Approver），后台「公司成员」管理。
- 企业协议价分级（`mro_price_tiers` 按公司×商品），报价/快速报价自动带出（协议价→历史价→目录价）。

### F13 商品资料与替代（Phase 3 · A5/A3）
- 商品技术资料 PDF/SDS/手册上传维护（`mro_product_docs`），前台详情页「技术资料」展示。
- 替代/互换关联（`mro_product_alternatives`），前台详情页「兼容 / 替代型号」展示。

### F14 数据深化（Phase 3 · K4/E4/L3/A4）
- 进价/毛利：成本维护 + 毛利额/毛利率（负数红显）。
- 库存预警：实时库存 vs 安全阈值，缺货/低库存 + 建议补货量。
- 易耗品周期采购提醒：采购周期 + 下次应采购日 + 逾期/临近状态。
- SKU 条码：报价单打印 Code128 条码（JsBarcode）。

### F15 单据合规与模板（Phase 3 · I3/M3）
- 报价单双语并列商务条款（越语主 + 中/英副）。
- 企业版合同模板（十条款、双语标题、可打印）。

## 六、单据状态机（核心）

### 6.1 报价单
```
draft ──► issued（带 valid_until 有效期）──► confirmed ──► 生成订单
              │                                  │
              └──► expired（超期自动）            └──► cancelled
              └──► cancelled
```
规则：仅 draft/issued 可编辑；超期由调度任务自动置 expired；confirmed 锁定内容并生成订单；内容哈希 `sha256(ksort json)` 防篡改。

### 6.2 订单
```
pending_sign ──► signed（卖方+客户双签）──► completed
      │                │
      └──► cancelled   └──► cancelled
```

### 6.3 单据流转总览
```
购物车 / 询价单（外部数据源，只读，经 Adapter 防腐层）
   ▼ 读取
报价单（draft → issued → confirmed / expired / cancelled）
   ▼ 客户确认
订单（pending_sign → signed → completed / cancelled）
   ▼ 双方签章（哈希锁定）
已生效订单（不可篡改，可追溯）
```

## 八、技术架构

```
前端（前台+后台）
   │ HTTPS（Nginx，强制 https；8080 隧道入口）
   ▼
Laravel/Bagisto（PHP 8.3-FPM）
   ├─ 前台 Shop（多语言/购物车/询价/报价生成/下单）
   ├─ 后台 Admin（商品增强/导入/单据中心/报价/询价/订单/配置）
   ├─ 单据模块 mro_quotes / mro_orders / mro_rfqs / mro_signatures / mro_audit_logs
   ├─ DocSourceAdapter（防腐层：询价单只读）
   └─ 命令/调度（导入、报价过期）
   │
MariaDB（bagisto，127.0.0.1:3306）
   │
自研报价系统 uvicorn :8001（XAMPP 客户端购物车导入生成报价，可选）
   │
Cloudflare 隧道（外网访问）
```

## 十、验收标准

### 功能验收
1. 4 语言浏览、搜索、详情正常。
2. 购物车下单全流程（地址-配送-支付-订单）可完成。
3. 询价提交→后台报价→邮件通知闭环。
4. 购物车生成报价单→后台调价/税/汇率→导出 Excel/PDF/邮件→客户确认→生成订单→双签→完成，全链路可用。
5. 报价超期自动失效；哈希篡改被检测。
6. CSV/XLSX 导入（含 URL 图片）成功率达 100%，后台可见导入记录。
7. 后台全部增强功能（27-40）可用。

### 非功能验收
- 局域网关键页面 HTTP 200、响应 <0.1s。
- 无 500 错误、无丢单、无库存/缓存不一致。
- 每日备份可恢复。

### 回归验收
- 单据闭环回归（20/20 断言通过）。
- HTTPS 全站无 mixed content（Playwright 0 失败）。
