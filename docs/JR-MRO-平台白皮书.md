## 一、执行摘要

JR-MRO 是一套**面向 B2B 工业品采购的 MRO 数字化交易平台**，覆盖五金工具、紧固件、劳保用品、焊接材料、磨料磨具、化学品、电气、办公耗材等 **13 大品类、500 个 SKU**，为北宁 / 北江工业区的工厂提供从**询价、报价、下单、电子签章到对账结算**的全链路在线服务。

平台针对 MRO 行业"**品类杂、SKU 多、价格面议、先询价后成交、多币种结算、含税开票**"的典型痛点，提供了区别于标准电商的 B2B 能力：

- **询价—报价—订单—签章** 的标准单据流转，价格透明、可追溯
- **多币种**（CNY 记账 / VND 结算 / USD 折算）+ **10% VAT 含税口径**的财务闭环
- **三语并行**（简体中文 / 繁体中文 / 越南语）友好界面，英文框架
- **全成本毛利核算**（进价含关税+内陆运费+仓储分摊），支撑真实定价决策

当前平台已完成财务核算闭环（成本→毛利→收入确认→应收→税费→资金四表），**达到局域网试营业标准**，可面向园区工厂先行开放。

## 二、行业背景与问题

### 2.1 MRO 采购的行业特性

MRO（Maintenance, Repair and Operations，维护/维修/运营物料）是制造业维持生产的"基础设施物料"，占制造企业采购额的约 3–8%，但管理复杂度远高于直接原材料：

| 特征 | 对采购方的影响 |
|---|---|
| 品类极杂、SKU 极多 | 同一订单常含五金+劳保+化工+电气多种类目 |
| 单价普遍不高、总单却大 | 价格敏感性高，需比价与议价 |
| 采购频次高、计划性弱 | 急需件占比高，响应速度关键 |
| 品牌替代 / 规格兼容普遍 | 需原厂型号、兼容替代、技术资料支撑 |
| 多币种、含税结算 | 发票、汇率、税负口径必须清晰 |

### 2.2 现状痛点

- 传统电话/邮件/QQ 询价：**报价不统一、无留痕、易错漏**；
- 纸质报价单与订单：**不可追溯、签章缺失、对账困难**；
- 价格与库存信息分散：**采购方无法在线比价、无法实时知道库存**；
- 财务口径混乱：**是否含税、什么币种、汇率多少**缺乏统一标注。

## 四、核心能力（B2B 关键价值）

### 4.1 商品与找货

- **13 大品类 / 500 SKU**：手动工具、电动工具、五金紧固件、劳保用品、焊接材料、磨料磨具、测量工具、化学用品、电气电工、办公用品等；
- **全量真实商品图**：500/500 商品配图，分类图标 13/13；
- **规格体系 + 原厂型号 + 兼容替代**：支持按规格/型号找货、替代件推荐；
- **筛选与搜索**：按分类、规格、价格区间条件筛选，响应 < 0.1s。

### 4.2 询价—报价—订单—签章（单据闭环）

- **购物车 / 询价单**：采购方可批量加入购物车或提交询价单；
- **报价单**：基于购物车或询价单生成，**每个商品价格可调、税率可调、汇率可调**，多语种标准报价单文档，**含 10% VAT 醒目标注**；
- **有效期**：报价单含有效期，**过期自动失效**，不可用于生成订单；
- **订单**：客户**在线确认报价**后生成正式订单；
- **电子签章**：卖方 + 客户**双签（记录式，哈希锁定）**，签章后内容不可篡改；
- **全生命周期可追溯**：报价单 ↔ 订单 ↔ 来源（购物车/询价）强关联，审计留痕（操作人/时间/IP/变更前后值）。

### 4.3 财务核算（已闭环）

| 环节 | 口径 |
|---|---|
| 进价成本 | 全成本 = 进价含关税(8%) + 内陆运费(3%) + 仓储分摊(2%) |
| 毛利 | 平均毛利率 **37.2%**，负毛利 0 |
| 含税 | 报价金额**已含 10% VAT**，单据显著标注 |
| 记账/结算 | 记账本位币 CNY、结算 VND（汇率 3900）、USD 折算（0.14） |
| 收入确认 | 按**交付签收**（delivered）确认收入；已收款/应收可区分 |
| 报表 | 应收账龄 / 存货结存 / 税费汇总 / 资金对账 **四表** |

### 4.4 多语种与本地化

- 简体中文 / 繁体中文 / 越南语 / 英文界面；
- 单据（报价单/订单）双语并列，面向中越资方；
- 面向越南北宁 / 北江工业区，支持越南电子交易法签章方向（记录式先行）。
