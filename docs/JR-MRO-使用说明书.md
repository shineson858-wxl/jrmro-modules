# JR-MRO 工业品采购平台 · 使用说明书

> **平台**：https://www.jrmro.com
> **适用**：B2B 采购方（工厂采购/仓管/总经理）与 JR-MRO 后台运营人员
> **版本**：V2.4（2026-10）

---

## 第一部分 · 前台（采购方使用）

### 1. 访问与语言

1. 浏览器打开 **https://www.jrmro.com**；
2. 右上角切换语言：**简体中文 / 繁體中文 / Tiếng Việt / English**；
3. 首次使用建议注册企业账号（需邮箱，用于接收报价/订单通知）。

### 2. 找商品

- **浏览**：顶部横楣按 13 大类导航（手动工具 / 电动工具 / 五金紧固件 / 劳保用品 / 焊接材料 / 磨料磨具 / 测量工具 / 化学用品 / 电气电工 / 办公用品等）；
- **搜索**：顶部搜索框输入品名 / 原厂型号 / SKU；
- **筛选**：分类页可按规格、价格区间等条件筛选，结果实时刷新；
- **商品卡片**：展示商品图、名称、含税价格（VND）、库存、新品标识。

### 3. 询价 / 加入购物车

- 想先询价的商品：点「**询价**」加入询价单；
- 确定要买的商品：点「**加入购物车**」；
- 可在询价单/购物车内调整数量，批量提交。

### 4. 生成报价单（核心步骤）

1. 进入**购物车或询价单**，点「**生成报价单**」；
2. 系统生成标准报价单，包含：
   - 每个商品的单价、数量、金额（可后台调价）；
   - **小计 → 增值税（10% VAT）→ 含税合计**；
   - 币种与汇率（VND/CNY/USD）；
   - **醒目标注：「本报价金额已含 10% 增值税」**；
3. 报价单含**有效期**，过期自动失效。

> 说明：B2B 模式下价格多为**面议**，报价单金额以双方确认后为准。

### 5. 确认报价 → 生成订单 → 电子签章

1. 收到报价单后（可在线查看 / 邮件接收），确认无误点「**确认报价**」；
2. 系统据此生成**正式订单**；
3. 进入「**电子签章**」：卖方 + 客户双签（记录式，内容哈希锁定，不可篡改）；
4. 双方签章完成后订单生效，等待**配送/自提**。

### 6. 收货与结算

- 货物送达后确认**收货**（交付签收 = 收入确认口径）；
- 结算方式：货到付款 / 银行转账（Vietcombank）；
- 付款后平台记录**核销**，你可在对账报表中查看往来账。

### 7. 常见问题（FAQ）

| 问题 | 解答 |
|---|---|
| 价格为什么是"面议"？ | MRO 大宗采购价格因人因量而异，先询价后成交更合理 |
| 报价含税吗？ | 含，所有报价单显著标注"已含 10% VAT" |
| 用哪种币种？ | 默认 VND 结算、CNY 记账，支持 USD 折算 |
| 忘记密码？ | 登录页"忘记密码"通过注册邮箱重置 |

## 第二部分 · 后台（JR-MRO 运营/财务使用）

> 后台入口：**https://www.jrmro.com/admin**（登录：admin@example.com）

### 8. 商品管理

| 功能 | 位置 | 操作 |
|---|---|---|
| 批量导入商品 | 商品 → 表格导入 | 上传符合规范的 CSV/XLSX（含图片 URL），自动入库上架 |
| 手动维护商品 | 商品列表 | 增/删/改、编辑规格/型号/价格/库存/图片 |
| 批量改价/库存 | 商品 → 批量操作 | 按 SKU 批量调整价格、库存、分类 |
| 图片管理 | 商品 → 图片库 | 集中上传/替换/删除商品图 |
| 上架审核 | 商品 → 待审 | 新导入商品经审核后上架 |

### 9. 单据中心（核心）

菜单集中管理全部业务单据：

1. **询价单**：接收前台询价 → 查看明细 → 转报价；
2. **报价单**：
   - 新建报价（基于购物车/询价单）；
   - **逐商品调价、调税率、调汇率**；
   - 设置有效期；发送给客户（邮件）；
   - 导出 Excel / PDF；
3. **订单**：报价确认后生成 → 记录签章 → 跟踪配送/收款；
4. **签章记录 / 审计日志**：全流程留痕（操作人/时间/IP/变更前后值）。

### 10. 财务与报表

| 模块 | 内容 |
|---|---|
| 进价成本 | 维护每个商品全成本；改价自动留痕（before/after+IP） |
| 经营看板 | 今日/本月成交、收入确认（已确认/已收款/应收）、缺货预警 |
| 销售分析 | ABC 分析、TOP 商品/客户 |
| 对账报表 | 月度成交、客户对账（CSV 导出） |
| **财务四表** | 应收账龄 / 存货结存 / 税费汇总 / 资金对账 |

### 11. 全局配置

- **汇率**：VND=3900、USD=0.14（可调，作为默认）；税率默认 10% VAT；
- **多语种内容**：商品名/分类/单据文案的中/越/英维护；
- **配送 / 支付**：配置配送方式与结算渠道。

### 12. 系统运维（管理员）

- **一键启动**：运行 `JR-MRO-一键启动.cmd`（自动拉起 Nginx/PHP-FPM/MariaDB + 更新端口转发）；
- **备份**：每日 03:00 自动 mysqldump，保留 7 份；
- **域名**：正式公网前将 APP_URL/证书统一为正式域名。
