# JR MRO 商城 · 行业实操整改优化建议书

> 视角：30 年工业 MRO 职业经理人　|　场景：越南北宁 / 北江等电子制造工业区实际操作　|　2026-10-18
> 方法：以 MRO 采购全流程（找货 → 询价 → 报价 → 下单 → 履约 → 结算 → 复购）遍历系统每个功能模块，逐项对照工业园区工厂的真实采购习惯提出整改建议。

---

## 〇、总体判断

系统在**电商功能完整性**上已相当扎实（购物车/询价/报价/订单/签章/导入/多语言都做了），但作为**面向越南工业区的 MRO 供应链平台**，目前更像「通用电商套了个工业主题壳」，距离「工厂采购员愿意天天用的工具」还有一段距离。核心差距不在功能多寡，而在**贴合 MRO 采购逻辑与越南本地履约/合规**。

三大战略性建议（贯穿全文）：
1. **从"卖货商城"转向"工厂采购工具"**——围绕找规格、替代、急单、账期、发票做文章，而非堆商品。
2. **把"价格"做成动态可谈的商务对象**，而非静态标价——这是 MRO 与大商超最大的不同。
3. **先打通"本地履约 + 结算合规"**，再谈流量与拉新——越南工厂最怕买得到却送不到、开不了票。

## 一、商品与数据层

### 现状
- 约 500 商品、74 分类、13 顶级大类，全库配图；多语言；CNY 基准价 + 汇率换 VND。
- 部分商品按自编码（MRO-BG-xxx），少量引用原厂型号。

### 行业痛点（北宁/北江实操）
- 工业区工厂采购，第一件事是**找规格/找原厂件号**：工程师嘴里报的是「NSK 6205ZZ」「3M 9002」「SKF 6305-2RS」这类**原厂型号**，不是你的自编码。目前系统几乎没有原厂型号（OEM/MPN）检索入口。
- MRO 品类是**海量 SKU + 规格参数**（尺寸、材质、螺纹、压力等级、耐温……），目前规格属性较弱，多数商品只有名称+图片，工程师无法按参数筛。
- 缺**替代/互换**意识：国产件替进口件、同类互换（6205ZZ 与 6205Z），工厂会问"有没有能替 XX 的"。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| A1 | 新增 **原厂型号(MPN/OEM No.)字段 + 独立检索**，商品名、MPN、规格三者可搜；海报/详情突出"兼容型号" | P0 |
| A2 | 建立**规格参数体系**（按品类定义属性：轴承→内径/外径/厚度/密封；紧固件→螺纹/长度/强度等级；工具→规格/功率），让工程师按参数筛选 | P0 |
| A3 | 引入**替代/互换**关联（同参数不同品牌可替换），详情页展示"可替换型号" | P1 |
| A4 | SKU 规范化 + 条码：给每个商品补**越南本地可扫码**的识别（QR/条码贴），仓库与工厂对接 | P1 |
| A5 | 商品页补**技术资料**（PDF 规格书、安全数据表 SDS 用于化学品/劳保），工厂 QA 需要 | P1 |

## 二、搜索与目录导航

### 现状
- 关键词搜索 + 13 大类横楣 + 分类图标 + 条件筛选（价格等）。

### 行业痛点
- 工厂采购员习惯**按"我要的物"直接搜型号**，搜不到就放弃；目前缺原厂型号检索（见 A1）。
- 缺**同义词/多语言搜索**：工程师输"螺丝"vs"bolt"，越南人输"ốc"，要能统一命中。
- 缺**历史/常用清单**：同一个工厂反复买同几样东西，应能"一键回购"。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| B1 | 搜索加**型号联想 + 模糊匹配 + 多语言同义词**（一个词表映射中/越/英/繁体） | P0 |
| B2 | 按品类提供**属性筛选面板**（不只价格），工厂能按规格缩圈 | P0 |
| B3 | 企业客户**"我的常用/上次购买"清单**，一键加购复购 | P0 |
| B4 | 缺货商品允许**"到货通知/预订"**，转化潜在急单 | P1 |

## 三、询价 RFQ 与报价（MRO 核心）

### 现状
- 前台询价 → 后台报价 → 邮件通知；购物车生成报价单；报价单可调价/税/汇率/有效期/导出/邮件/多语种。
- 有状态机、哈希防篡改、审计。

### 行业痛点
- 工业区 MRO 询价**往往是批量、多品、带图纸/照片**，目前询价表单较简单，无法传附件、无法一次询多个商品。
- 报价响应速度是关键——工厂同时问 3-5 家，**谁先报谁有单**；目前人工后台报价，缺快速报价助手/模板价。
- 缺**报价对比/议价记录**：客户要求"再降 5%"的往来，缺留痕。
- 报价单是 MRO 的命脉，目前**不直接出含税总价、有效期、付款条件、交付期**一体化的正式商务件，仍需加强。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| C1 | 询价支持**多商品批量 + 附件上传（图纸/清单 Excel）**，一次询价带多条明细 | P0 |
| C2 | 后台报价提供**模板价/历史价速填 + 批量报价**（同一客户多 SKU 一次报价），提升响应速度 | P0 |
| C3 | 报价单补**标准商务要素**：含税总价、付款条件（账期/TT）、交付期、有效期、质保、运输条款，一键转正式 PDF | P0 |
| C4 | 增加**议价/跟进记录**（客户还价 → 我方再报，状态保留历史），报价全链路留痕 | P1 |
| C5 | 建立**客户历史成交价库**，二次报价自动带出上次价格供参考 | P1 |

## 四、价格、货币与结算

### 现状
- CNY 基准 + 汇率换 VND；税率默认 10%；支持 COD + Vietcombank 转账。

### 行业痛点
- 越南工业区实操：**对外报价/合同常用美元或越南盾含税价**，人民币主要在中国供应链侧。目前"CNY 基准 + 汇率换算"对工厂客户不直观，且汇率波动需频繁维护。
- **增值税发票（红字发票/VAT invoice）是 B2B 刚需**，工厂必须拿到合规发票才能付款入账；目前无发票管理。
- **大客户月结/账期（30/60 天）**是 MRO 常见结算方式，目前只有即时支付，缺信用/账期。
- 结算主体需**对公**：越南企业要求对公银行账户、公司抬头、税号；目前下单流程对"企业客户"识别较弱。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| D1 | 支持**多币种报价切换**（VND 含税价 / USD / CNY），报价单与结账均可选；汇率做**全局 + 定时可维护** | P0 |
| D2 | 上线**越南增值税发票（VAT invoice）**：下单/报价可开含税红字发票，按越南税法格式出票、留痕 | P0 |
| D3 | 增加**企业客户认证 + 信用额度 + 账期（月结）**，大客户走"挂账/月结/对公转账" | P0 |
| D4 | 结账突出**公司抬头 + 税号（MST）**采集，用于开票与对公结算 | P0 |
| D5 | 汇率与税率的**变更留痕 + 生效日期**，避免历史单据与对账争议 | P1 |

## 五、库存、缺货与履约

### 现状
- 有库存字段、库存显示、购物车/订单；无缺货预订（B4 已列）。

### 行业痛点
- 工业区 MRO 最怕**"看得见、加得了车，付完款没货"**；需要**实时可售库存 + 缺货承诺**。
- **急单**（产线停机抢修）是最高毛利场景，需要"现货标识 + 加急通道 + 当天到厂"。
- 缺**仓库/库存地点**概念：北宁、北江可能有分仓，工厂下单要知道从哪个仓发。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| E1 | 商品页与购物车显示**实时可售库存**（现货/需订货），缺货禁下单或转询价 | P0 |
| E2 | 加**"现货/加急"标识**，支持加急订单（加急费可选），承诺北宁/北江当天到厂 | P0 |
| E3 | 引入**多仓库/多库存点**，结账可选发货仓；库存按仓扣减 | P1 |
| E4 | **安全库存预警 + 自动补货建议**（对运营），避免热销缺货 | P1 |

## 六、物流与配送（本地化关键）

### 现状
- 越南区划地址三级联动已接前台结账（历史已实现）；配送方式待完善；COD + 转账。

### 行业痛点
- 工厂希望**直送到厂（车间/仓库门口）**，地址要精确到厂区/车间，目前地址粒度可能不够。
- 时效承诺很重要：北宁到北江**当日/次日达**是竞争力；需要**可承诺的配送时效**。
- **自提/到店取货**（工厂采购顺路来提）很常见，需支持。
- 缺**配送跟踪**（订单状态 → 出库 → 在途 → 送达）与签收。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| F1 | 地址支持**厂区/车间/收货联系人 + 门卫备注**；越南区划精确到乡/坊 | P0 |
| F2 | 明确**配送时效承诺**（当日达/次日达/3 天）+ 按距离/金额的运费规则；上线"自提"选项 | P0 |
| F3 | 增加**订单配送状态机**（待发货 → 已出库 → 在途 → 已签收），后台可更新物流 | P1 |
| F4 | 对工业区大客户提供**月度配送/定期补货**计划单 | P2 |

## 七、支付与收款

### 现状
- COD + Vietcombank 银行转账；在线支付未接入。

### 行业痛点
- **在线支付不是越南 B2B MRO 的主流**（工厂走对公转账/月结），COD 对高价值工业品风险高。
- 缺**对公转账的"付款凭证上传 + 后台到账确认"**流程——工厂打款后要能对账。
- 未来可补 VNPay/MoMo/ZaloPay，但**优先级低于对公结算**。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| G1 | 上线**对公转账 + 付款凭证上传**：订单页生成转账信息（收款户/账号/银行），客户上传回单，后台核销 | P0 |
| G2 | COD 增加**金额上限与区域控制**，降低坏账 | P1 |
| G3 | 视客户结构评估接入 VNPay/ZaloPay（面向小型商户/个人单） | P2 |

## 八、客户、会员与企业化

### 现状
- 客户注册、订单、邮件通知；企业信息采集较弱。

### 行业痛点
- 工业区是**企业采购**为主，客户=公司而非个人。需要**企业账户、多收货地址、多个采购员、部门/项目**维度。
- 缺**客户分级**（VIP/批发/散客）与对应**阶梯价**——MRO 批发价 vs 零售价是核心。
- 缺**采购员账号与权限**（一个公司多个下单人），及"以公司为单位"的账单与信用。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| H1 | 强化**企业账户**：公司注册、税号、对公信息、多收货地址、多联系人 | P0 |
| H2 | 建立**客户分级 + 阶梯价/协议价**（零售价、批发价、协议价），不同客户见不同价 | P0 |
| H3 | 支持**公司下多个采购员账号 + 角色权限**（下单/审批/查看） | P1 |
| H4 | 企业客户**专属价格与协议价**在报价单/下单时自动带出 | P1 |

## 九、多语言与本地化（专业术语）

### 现状
- 4 语言（简中/繁中/越/英）已覆盖界面、分类、商品名。

### 行业痛点
- 工厂实际操作中：**越南本地采购/仓管用越南语，工程师用英文规格术语**；中文多用于中方供应链沟通。
- 缺**工业专业术语词典**：比如"轴承""密封圈""气动接头"的越/英准确翻译，普通翻译可能不专业。
- 缺**度量衡/单位本地化**：越南用公制，需统一（mm/kg/个/盒/包）。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| I1 | 建立**MRO 专业术语词库**（越/中/英对照，含分类、属性、规格名），避免直译错误 | P0 |
| I2 | **单位/包装本地化**：明确计量单位与包装规格（每盒/每包数量），工厂采购按件/按盒下单 | P1 |
| I3 | 关键单据（报价单/订单/发票）**双语并列**（越语主 + 中文或英文副），方便中越双方核对 | P1 |

## 十、单据中心（报价/订单/签章）

### 现状
- 单据中心统一报价/询价/订单；状态机；哈希防篡改；审计；记录式签章。

### 行业痛点
- **电子签章合规**：越南《电子交易法》2023 修订版允许电子签名，但**企业间具法律效力的电子签章**需符合规定；当前记录式签章（哈希锁定）保障了不可篡改，但**法律效力/第三方 CA**仍弱。
- 缺**单据导出为越南合规商务文档**（含越南税号、公司信息、签章位、二维码核验）。
- 缺**单据检索/归档/报表**：工厂对账需要按月汇总。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| J1 | 单据增加**越南合规商务要素**（公司抬头+税号+越南地址+签章位），导出 PDF 含**核验二维码**（哈希可在线校验） | P0 |
| J2 | 评估接入**越南本地电子签名/CA 服务**（如 VNPT-CA、Viettel 或国际 eSign）增强法律效力 | P1 |
| J3 | 单据中心加**报表/对账**：按月/客户汇总报价与成交额，导出 Excel 供财务对账 | P1 |
| J4 | 单据全生命周期**时间线与状态**已较完善，建议加"操作人"可视化留痕（谁改的价/何时） | P1 |

## 十一、后台运营与销售

### 现状
- 商品增强（27-40）、导入、单据中心、报价/询价管理、系统配置。

### 行业痛点
- 缺**销售员/业务员维度**：MRO 靠业务员跟单，应能**按业务员分配客户、看自己的业绩**。
- 缺**导购/报价助手**：业务员要快速查"这个客户上次买什么价、有没有货"。
- 缺**客户全景视图**：一个客户的全部询价/报价/订单/欠款/发票汇总。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| K1 | 增加**业务员（Sales Rep）角色**：客户绑定业务员，后台按业务员看客户、单据、业绩 | P1 |
| K2 | 建设**客户 360° 视图**：客户页聚合全部询价/报价/订单/发票/欠款 | P1 |
| K3 | 后台加**快速报价工具**：查客户历史价 + 现库存 + 一键生成报价 | P1 |
| K4 | 导入/商品数据增加**"上次供应商价/进价"**字段，辅助报价毛利决策 | P2 |

### 行业痛点

|---|---|---|
| L1 | 后台 Dashboard 增加**核心经营看板**：今日成交、本月销售额、Top 商品/客户、缺货清单 | P0 |
| L2 | 提供**ABC/品类/客户销售分析**报表（导出 Excel） | P1 |
| L3 | **易耗品周期采购提醒**：对周期性耗材按上次采购时间自动提醒复购 | P2 |

## 十三、安全与合规

### 现状
- production、DEBUG 关、HTTPS 自签、强密码、审计；在线支付/隐私政策未做。

### 行业痛点
- 越南 **PDPD（个人数据保护法）2023** 对企业处理客户数据有合规要求，需**隐私政策 + 数据采集授权**。
- 正式公网需要 **Let's Encrypt 正式证书 + 正式域名固定地址**。
- 面向企业，合同/报价需**符合越南合同法与电子交易法**。

### 整改建议
| # | 建议 | 优先级 |
|---|---|---|
| M1 | 上线**隐私政策 + 注册用户条款 + 数据授权**（PDPD 合规） | P0 |
| M2 | 上线前换**Let's Encrypt 正式证书 + 固定域名** | P0 |
| M3 | 建立**企业版服务条款/销售合同模板**（含税、账期、交付、质保、争议解决） | P1 |
| M4 | 后台加**登录安全**：限流、失败锁定、可选 2FA | P1 |

## 十四、上线就绪（P0 聚合清单）

按"能真正在越南北宁/北江工业区跑起来"的标准，**上线前必须补齐的 P0**：

| 类 | 项 |
|---|---|
| 找货 | 原厂型号检索(A1)、规格筛选(A2)、专业搜索(B1)、常用清单复购(B3) |
| 交易 | 批量询价+附件(C1)、模板/历史价报价(C2)、标准商务报价单(C3) |
| 结算 | 增值税发票(D2)、企业认证+账期(D3)、对公结算+凭证核销(G1)、多币种报价(D1) |
| 履约 | 实时库存(E1)、现货/加急(E2)、配送时效+自提(F2)、厂区地址(F1) |
| 客户 | 企业账户+多地址+分级协议价(H1/H2)、专业术语词库(I1) |
| 合规 | 隐私政策(M1)、正式证书+固定域名(M2)、合规单据+核验码(J1) |

> 完成上述 P0，系统即可真正服务北宁/北江工业区工厂客户；P1/P2 为持续迭代增强。
