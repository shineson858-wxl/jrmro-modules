# JR-MRO — MRO 工业品商城增强模块（基于 Bagisto 2.x）

面向越南 MRO（非生产性物料 / 工业品）采购场景的 **Bagisto 增强模块集**。在 Bagisto 2.x 基础上，自研实现了后台「单据中心」（询价 / 报价 / 订单 / 电子签章）、商品成本与毛利核算、经营看板与财务报表、客户 360、业务员与协议价、多语种界面、电子表格批量导入、越南行政区划发货地址联动等能力。

> 本仓库仅包含**自研增强代码与文档**。Bagisto 官方基础代码请使用官方仓库，本模块按官方包的目录结构集成。

---

## 模块结构

```
admin/             后台增强（Controllers / Views / Helpers / Exports / Routes）
shop/              前台增强（报价单生成等）
database/          自研数据表 DDL（schema.sql）、越南行政区划（vn_country_states.sql）
docs/              白皮书、PRD、使用说明书、测试报告、优化实施计划
scripts/           部署与运维脚本
LICENSE            MIT
README.md
.env.example       配置模板（占位符，生产请自配）
```

## 核心功能

- **单据中心**：询价(RFQ) → 报价单（价格 / 税率 / 汇率可调）→ 客户确认 → 正式订单 → 双方电子签章 → 全程可追溯
- **商品成本与毛利**：全成本口径（进价含关税 + 内陆运费 + 仓储分摊），自动识别负毛利
- **经营看板与财务报表**：应收账龄、存货结存、税费汇总、资金对账
- **企业化能力**：客户 360、业务员、分级协议价、信用账期、对公核销
- **多语种**：简体中文 / 繁体中文 / 越南语 / 英文
- **电子表格批量导入商品**：含图片、下拉校验、导入历史与定时任务
- **越南行政区划**：省市县乡四级地址联动，接入发货 / 订单地址

## 集成方式

1. 在已安装 Bagisto 2.x 的 Laravel 工程中，将 `admin/`、`shop/` 下的文件按对应 `packages/Webkul/...` 路径覆盖部署；
2. 导入 `database/schema.sql` 创建自研数据表（`mro_*`）；
3. 复制 `.env.example` 为 `.env`，配置数据库与应用地址，并生成 `APP_KEY`；
4. 执行 `php artisan migrate`、`php artisan storage:link`，按需配置队列与定时任务。

详细部署与使用见 `docs/` 下的白皮书与使用说明书。

## 说明

- 项目文档中出现的服务器地址、后台账号、数据库口令均为**占位符**，生产环境请自行配置，切勿使用示例口令。
- 越南电子签章相关能力为记录式签章（记录式电子签名），正式商用前请结合越南《电子交易法》(2023修订版) 及本地 CA 服务评估合规性。
